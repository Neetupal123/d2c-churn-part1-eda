# D2C Customer Churn Analysis

## Project Objective

Analyze customer churn patterns for a D2C brand using customer, order, support, campaign, and web activity datasets.

## Files Included

- eda_audit.ipynb
- data_quality_report.md
- business_memo.md
- requirements.txt

## Key Analysis Areas

- Data quality assessment
- Customer behavior analysis
- Revenue analysis
- Campaign engagement
- Support-ticket analysis
- Churn-risk hypothesis generation
